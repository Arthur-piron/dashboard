# Dashboard — Front end

React 19 + Vite, plain JavaScript.

```bash
npm install
npm run dev      # http://localhost:5173 — proxies /api to the Dockerised API on :8080
npm run build    # static files in dist/
npm run lint
npm run build
```

The documentation lives in the repository's `docs/` folder:

- [docs/frontend.md](../docs/frontend.md) — structure, the API client, the dashboard grid, theming,
  responsive rules
- [docs/api.md](../docs/api.md) — the endpoints this app calls
- [../README.md](../README.md) — the project, and the rest of the documentation
